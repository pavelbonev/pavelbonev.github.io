Questions et réponses

Comment me connecter ?

Avec votre compte Google. Nous recevons seulement un numéro associé à votre compte, pas votre nom ni votre e-mail. Choisissez ensuite un pseudo ; vous pouvez le modifier à tout moment dans le menu qui affiche votre pseudo.

Jusqu’à quand puis-je modifier mon pronostic ?

Jusqu’au début du match. Après le coup d’envoi, le pronostic est verrouillé. Le champion peut être choisi jusqu’au début de la phase à élimination directe.

Comment les points sont-ils comptés ?

3 points pour le score exact, 1 point pour la bonne issue (victoire, nul ou défaite), 10 points pour le champion. Seul compte le résultat à l’issue du temps réglementaire de 90 minutes. À égalité de points, le joueur qui a le plus de pronostics justes (scores exacts et bonnes issues réunis) passe devant, puis celui qui a fait le moins de pronostics.

Pourquoi ne reçois-je aucune notification ?

Euromondo n’envoie pas de notifications push. Les résultats et les messages arrivent en direct tant que l’application ou l’application web est ouverte.

Quelqu’un m’écrit des choses offensantes. Que puis-je faire ?

Écrivez-nous avec le pseudo du joueur et ce qu’il a écrit. Nous supprimons les messages et pseudos offensants.

Qu’apporte l’abonnement ?

Les essaims : vos propres groupes, avec leur propre classement et leur chat. Tout le reste est gratuit. L’abonnement coûte environ 3 € par an ; le prix exact est indiqué dans la boutique.

Comment retrouver mon abonnement sur un nouveau téléphone ?

L’abonnement est lié à votre compte Euromondo. Connectez-vous sur le nouveau téléphone avec le même compte, et les essaims sont débloqués.

Un abonnement pris sur Android fonctionne-t-il sur iPhone et dans le navigateur ?

Oui. Il fonctionne partout où vous vous connectez avec le même compte Euromondo. Il n’est pas vendu dans le navigateur : achetez-le dans l’application.

Comment résilier l’abonnement ?

Dans la boutique où vous l’avez acheté : sur Android dans Google Play → Abonnements, sur iPhone dans Réglages → votre nom → Abonnements. Il reste ensuite actif jusqu’à la fin de l’année déjà payée. Supprimer l’application ou votre compte ne le résilie pas.

Comment supprimer mon compte ?

Dans l’application ou l’application web : ouvrez le menu qui affiche votre pseudo et choisissez « Supprimer le compte ». Pas à pas : Supprimer votre compte.
